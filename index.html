Estrutura

O HTML é a linguagem de marcação usada para criar páginas web. Ele define a estrutura do conteúdo, como títulos, parágrafos, listas e links.

Layout

O CSS é a linguagem de estilos usada para definir a aparência das páginas web. Ele permite controlar cores, fontes, espaçamento e layout geral do conteúdo.

Extras

Além do HTML e CSS, existem outras tecnologias que podem ser usadas para melhorar a experiência do usuário, como JavaScript para interatividade e frameworks para facilitar o desenvolvimento.
